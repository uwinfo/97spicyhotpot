# 批次上傳產品 / 賣場流程（`admin.97spicyhotpot.com`）

> 適用情境：從 Excel 等表單一次建立多個商品 + 賣場，含主圖、分類、商品頁內容。
> 整理時間：2026-06-04（基於 06-03、06-04 兩次實戰）。

---

## 1. 流程總覽

1. **建商品** — `PATCH /api/product`，`uid: ''` = 新建
2. **上傳產品圖** — `POST /api/product/upload-temp-image`
3. **掛產品圖** — `PATCH /api/product` 帶 `firstImageUrl` + `originalFirstImageUrl`
4. **審核售價** — `PATCH /api/product/approve-sale-price?productUid=...`（賣場吃已審核價）
5. **上傳賣場圖** — `POST /api/market/upload-temp-image`
6. **建賣場（空殼）** — `PATCH /api/market`，`uid: ''` + 子陣列全空 → response 直接回 `{uid, ...}`
7. **完整 PATCH 賣場** — `PATCH /api/market` 帶新 `marketUid` + `marketImages` + `marketProducts` + `marketCategories`

每筆共 5 個 fetch（建商品 → 上傳產品圖 → PATCH 圖 → approve → 上傳賣場圖 → 賣場空殼 → 賣場完整）= **7 calls**。

## 2. 商品（Product）

### 2.1 新增商品

`PATCH /api/product`

```json
{
  "uid": "",
  "name": "免過濾麻辣醬",
  "barcode": null,
  "modelNo": null,
  "isVirtual": "N",
  "backendMemo": "型態：醬狀\n規格：一公斤\n葷素類別：五辛素\n",
  "enShippingTemperatureZone": 100,
  "temporaryMinSalePrice": 99999,
  "temporaryMaxSalePrice": 99999,
  "originalPrice": null,
  "maxSoldQty": 0,
  "tags": [],
  "productSets": null,
  "productWeightGram": null,
  "storageLocation": null,
  "description": ""
}
```

回傳 `200 "true"`（**不回 UID**，要拿 UID 必須再打 `/api/product/list` 過濾）。

#### 溫層編碼 `enShippingTemperatureZone`

| 值 | 意義 |
|----|------|
| 100 | 常溫 |
| 200 | 冷藏 |
| 300 | 冷凍 |

#### 關於 `backendMemo`

純文字，多用來放 Excel 那種「型態 / 規格 / 葷素類別」結構化資訊。前端會渲染保留換行。

### 2.2 上傳產品圖 & 掛到商品

```
POST /api/product/upload-temp-image
Content-Type: multipart/form-data
file=<binary>
```

回傳：
```json
{
  "url": "/upload/product/temp-image/20260604153037574qwmyh.webp",
  "originalUrl": "/upload/product/temp-image/20260604153037574qwmyh_o.png"
}
```

然後 `PATCH /api/product` 帶上：
```json
{
  "uid": "<product uid>",
  "firstImageUrl": "<url from upload>",
  "originalFirstImageUrl": "<originalUrl from upload>",
  ...所有其他欄位（PATCH 是全量替換，不送=被清空）
}
```

**重點**：`firstImageUrl` 寫入後 server 會把 temp 路徑自動搬到 `/upload/product/<productUid>/...`。

### 2.3 審核售價

賣場必須掛**已審核售價**的商品，否則 PATCH /api/market 會回 `請先設定商品的最低售價`。

```
PATCH /api/product/approve-sale-price?productUid=<uid>
```

把 `temporaryMinSalePrice` / `temporaryMaxSalePrice` 提升為正式的 `minSalePrice` / `maxSalePrice`。回 `200 "true"`。

## 3. 賣場（Market）

### 3.1 上傳賣場圖

```
POST /api/market/upload-temp-image
Content-Type: multipart/form-data
file=<binary>
```

回傳：
```json
{
  "url": "/upload/market/temp-image/...webp",
  "originalUrl": "/upload/market/temp-image/..._o.png"
}
```

**注意**：每筆賣場都要獨立上傳一次。完整 PATCH 賣場（含 marketImages）後，server 會把 temp-image 自動搬到 `/upload/market/<marketUid>/...`，原 temp 路徑失效。

### 3.2 第一段 PATCH：建空殼拿 marketUid

```
PATCH /api/market
```

```json
{
  "uid": "",
  "name": "<產品名>",
  "urlCode": "<product uid，保唯一>",
  "startAt": "2026-06-04T00:00:00+08:00",
  "endAt": "2099-12-31T23:59:59+08:00",
  "isPrivate": "N",
  "description": "<p>型態：醬狀<br>規格：一公斤<br>葷素類別：五辛素</p>",
  "outlineMarkdown": "* 型態：醬狀\n* 規格：一公斤\n* 葷素類別：五辛素",
  "backendMemo": "",
  "marketTags": [],
  "marketImages": [],
  "marketProducts": [],
  "marketCategories": []
}
```

**回傳直接帶完整 market 物件，含新 `uid`**（不用再 list 搜尋）：
```json
{
  "id": 124,
  "uid": "3b0a8947-7319-4b85-b3b9-be8932dc50fc",
  "name": "免過濾麻辣醬",
  ...
}
```

#### 欄位對應

| 欄位 | 意義 |
|------|------|
| `urlCode` | 賣場前端 URL slug。建議用 `product.uid` 保唯一（特別是同名不同規格場景） |
| `description` | 商品頁內容（HTML）|
| `outlineMarkdown` | 賣場簡述（Markdown），server 自動轉成 `outlineHtml` |
| `isPrivate` | `'Y'` / `'N'`（**不是 bool**，bool 會被白名單擋） |

### 3.3 第二段 PATCH：補完整資料

```json
{
  "uid": "<marketUid 從第一段 response 拿>",
  "name": "...",
  ... 同第一段所有欄位 ...,
  "marketImages": [
    {
      "marketUid": "<marketUid>",
      "imageUrl": "<url from upload>",
      "originalImageUrl": "<originalUrl from upload>",
      "sort": 1
    }
  ],
  "marketProducts": [
    {
      "productUid": "<product uid>",
      "salePrice": 99999,
      "sort": 1
    }
  ],
  "marketCategories": ["<賣場分類 uid，見 §4>"]
}
```

回 `200` + 完整 market 物件。

## 4. 分類：賣場分類 ≠ 網站前端目錄

⚠️ **這是 06-04 踩過的雷**：admin 後台有**兩套獨立**的分類系統，名字結構可能相同（都有「湯．味研所 > 麻辣系列」），但 UID 完全不同。

### 4.1 兩個 endpoint

| 用途 | endpoint | 用在哪 |
|------|----------|--------|
| 前端網站 navigation menu | `GET /api/front-menu/list` | 網站目錄管理頁、前端站台 menu |
| **賣場分類** | `GET /api/universal/market-category` | **賣場的 `marketCategories` 欄位吃這個** |

### 4.2 取賣場分類 UID

## 5. PATCH 子陣列 = 全量替換（重要踩雷）

`PATCH /api/market` 的子陣列（`marketImages` / `marketProducts` / `marketCategories` / `marketTags`）是**全量替換**，且 **server 不做 diff**：

- 子項**不送** → 該關聯被刪
- 子項**送出且不帶 uid** → server 嘗試 INSERT
- 子項**送出且帶既有 row uid** → server 走 UPDATE

### 雷案例：update 既有賣場的分類

如果只想改 `marketCategories`、但 `marketProducts` / `marketImages` 不變，**必須**從 detail 把既有 child 物件**含 uid** 一起送回：

```javascript
const dj = await (await fetch(`/api/market?uid=${marketUid}`)).json();

await fetch('/api/market', {method:'PATCH', credentials:'include',
  headers:{'Content-Type':'application/json'},
  body: JSON.stringify({
    uid: dj.uid,
    name: dj.name,
    urlCode: dj.urlCode,
    // ... 其他欄位都從 dj 帶 ...
    marketImages: dj.marketImages.map(i => ({
      uid: i.uid,            // ← 關鍵：帶既有 uid
      marketUid: dj.uid,
      imageUrl: i.imageUrl,
      originalImageUrl: i.originalImageUrl,
      sort: i.sort
    })),
    marketProducts: dj.marketProducts.map(p => ({
      uid: p.uid,            // ← 關鍵：帶既有 uid
      marketUid: dj.uid,
      productUid: p.productUid,
      salePrice: p.salePrice,
      sort: p.sort
    })),
    marketCategories: ['<新 category uid>']
  })
});
```

否則會 500 `MarketVsProductHelper.AddMarketVsProduct line 69` — PK constraint violation。

### 為什麼建立流程沒踩到？

新建賣場時，第一段 PATCH 是空殼（沒 children）、第二段才一次新增完整 children → 永遠是 INSERT，不會跟既有衝突。這個雷只在 **update 既有賣場**時才現形。

## 6. 圖片 host 與 CORS（無法跨域 reuse 圖）

- 所有上傳圖實際 host 在 `www.97spicyhotpot.com`（前端站台）。
- `admin.97spicyhotpot.com` **不 serve `/upload/...`** → 從 admin 內 fetch 既有圖會 404。
- 從 admin 內跨 origin fetch `www.97spicyhotpot.com/upload/...` 被 CORS 擋。

→ **無法用 fetch 既有圖再重上傳的方式 reuse**。

每筆都要重新上傳本機檔案。

### Playwright 內批次上傳本機檔案的技巧

base64 注入 1.1MB 不切實際。可用：

```javascript
// 1. 動態建一個隱藏 file input 並 hook on-change
evaluate(() => {
  const inp = document.createElement('input');
  inp.type = 'file'; inp.id = '__bike_file_inp';
  inp.style = 'position:fixed;top:0;left:0;opacity:0.01;z-index:99999';
  document.body.appendChild(inp);
  inp.addEventListener('change', () => {
    if (inp.files[0]) window.__bike_file = inp.files[0];
  });
});

// 2. 點 input 觸發 file_chooser
click('#__bike_file_inp');

// 3. Playwright file_upload 把本地檔放進去
file_upload(['<path>/product-placeholder-待上傳.png']);

// 4. 之後所有迴圈都 reuse window.__bike_file 做 FormData
evaluate(async () => {
  const file = window.__bike_file;
  const fd = new FormData();
  fd.append('file', file, file.name);
  await fetch('/api/market/upload-temp-image', {method:'POST', credentials:'include', body: fd});
});
```

注意：頁面 navigate 後 `window.__bike_file` 會清掉，要重做一次 inject + file_chooser + file_upload。

## 7. 整合範例：建商品 + 賣場 + 圖（單筆 7 calls）

```javascript
async function createOne(item, file, categoryUid) {
  // 1. 建商品空殼
  const r1 = await fetch('/api/product', {method:'PATCH', credentials:'include',
    headers:{'Content-Type':'application/json'},
    body: JSON.stringify({
      uid: '', name: item.name, barcode: null, modelNo: null,
      isVirtual: 'N', backendMemo: item.memo,
      enShippingTemperatureZone: item.zone,
      temporaryMinSalePrice: 99999, temporaryMaxSalePrice: 99999,
      originalPrice: null, maxSoldQty: 0, tags: [], productSets: null,
      productWeightGram: null, storageLocation: null, description: ''
    })
  });
  // server 不回 uid，要 list 找
  const lr = await fetch(`/api/product/list?currentPage=1&pageSize=5&keyword=${encodeURIComponent(item.name)}&backendMemo=&isVirtual=&enShippingTemperatureZone=`, {credentials:'include'});
  const lj = await lr.json();
  const productUid = lj.list.find(p => p.name === item.name && p.backendMemo === item.memo).uid;

  // 2. 上傳產品圖
  const fdP = new FormData(); fdP.append('file', file, file.name);
  const u1 = await fetch('/api/product/upload-temp-image', {method:'POST', credentials:'include', body: fdP});
  const u1j = await u1.json();

  // 3. PATCH 商品 帶圖
  await fetch('/api/product', {method:'PATCH', credentials:'include',
    headers:{'Content-Type':'application/json'},
    body: JSON.stringify({
      uid: productUid, name: item.name, isVirtual: 'N',
      backendMemo: item.memo, enShippingTemperatureZone: item.zone,
      temporaryMinSalePrice: 99999, temporaryMaxSalePrice: 99999,
      maxSoldQty: 0, tags: [],
      firstImageUrl: u1j.url, originalFirstImageUrl: u1j.originalUrl,
      description: ''
    })
  });

  // 4. 審核售價
  await fetch(`/api/product/approve-sale-price?productUid=${productUid}`, {method:'PATCH', credentials:'include'});

  // 5. 上傳賣場圖
  const fdM = new FormData(); fdM.append('file', file, file.name);
  const u2 = await fetch('/api/market/upload-temp-image', {method:'POST', credentials:'include', body: fdM});
  const u2j = await u2.json();

  // 6. PATCH 賣場空殼
  const shell = {
    uid: '', name: item.name, urlCode: productUid,
    startAt: '2026-06-04T00:00:00+08:00', endAt: '2099-12-31T23:59:59+08:00',
    isPrivate: 'N',
    description: `<p>${item.memo.replaceAll('\n','<br>').replace(/<br>$/,'')}</p>`,
    outlineMarkdown: item.memo.split('\n').filter(Boolean).map(l => `* ${l}`).join('\n'),
    backendMemo: '', marketTags: [], marketImages: [], marketProducts: [], marketCategories: []
  };
  const r2 = await fetch('/api/market', {method:'PATCH', credentials:'include',
    headers:{'Content-Type':'application/json'}, body: JSON.stringify(shell)});
  const marketUid = (await r2.json()).uid;

  // 7. PATCH 賣場完整
  await fetch('/api/market', {method:'PATCH', credentials:'include',
    headers:{'Content-Type':'application/json'},
    body: JSON.stringify({
      ...shell, uid: marketUid,
      marketImages: [{marketUid, imageUrl: u2j.url, originalImageUrl: u2j.originalUrl, sort: 1}],
      marketProducts: [{productUid, salePrice: 99999, sort: 1}],
      marketCategories: [categoryUid]
    })
  });

  return {productUid, marketUid};
}
```

## 8. 踩雷清單（彙整）

| # | 雷 | 解法 |
|---|----|------|
| 1 | `GET /api/product`（不帶 uid）→ 400 | 用 `/api/product/list` |
| 2 | `PATCH /api/product` 新建不回 UID | 再打 list 過濾 keyword + backendMemo |
| 3 | 賣場分類 UID 用錯（front-menu vs market-category） | 用 `/api/universal/market-category` |
| 4 | 兩段 PATCH market — 客戶端自產 UID 想一次完成 → 404「查無賣場資料」 | 嚴格區分 `uid=''` 新建 / `uid=existing` 更新 |
| 5 | `marketCategories` 是 string array、`marketProducts/marketImages` 是 object array | `marketCategories: ['<uid>']` vs `marketProducts: [{...}]` |
| 6 | Update market 子陣列直接送 → 500 PK violation | 帶上既有 child 的 `uid` 走 update |
| 7 | 商品未審核售價 → 賣場 PATCH 報「請先設定商品的最低售價」 | 先 `approve-sale-price` |
| 8 | `isPrivate: false` → 「輸入值不在白名單裡」 | 用 `'Y'` / `'N'` 字串 |
| 9 | temp-image 在 PATCH 後會被搬到正式路徑，不能 reuse 同一個 URL 給多筆 | 每筆獨立上傳 |
| 10 | admin domain 不 serve `/upload/...`，CORS 擋 www domain | 上傳本機檔案，不能 reuse |

## 9. 對應的網路請求總覽

| 動作 | Method | URL | 主要 input | 回傳 |
|------|--------|-----|-----------|------|
| 建/改商品 | PATCH | `/api/product` | JSON body | `"true"` 或 detail |
| 上傳產品圖 | POST | `/api/product/upload-temp-image` | FormData `file` | `{url, originalUrl}` |
| 商品 detail | GET | `/api/product?uid=...` | — | product 物件 |
| 商品 list | GET | `/api/product/list?...` | query | `{list, totalRecord, pager}` |
| 審核售價 | PATCH | `/api/product/approve-sale-price?productUid=...` | — | `"true"` |
| 刪商品 | DELETE | `/api/product?uid=...` | — | `"true"` |
| 建/改賣場 | PATCH | `/api/market` | JSON body | market 物件 |
| 上傳賣場圖 | POST | `/api/market/upload-temp-image` | FormData `file` | `{url, originalUrl}` |
| 賣場 detail | GET | `/api/market?uid=...` | — | market 物件（含 marketProducts/marketImages/marketCategories）|
| 賣場 list | GET | `/api/market/list?...` | query | `{list, totalRecord, pager}` |
| 刪賣場 | DELETE | `/api/market?uid=...` | — | `"true"` |
| 賣場分類樹 | GET | `/api/universal/market-category` | — | 分類巢狀樹 |
| 網站前端 menu 樹 | GET | `/api/front-menu/list` | — | 巢狀樹（**不是**賣場分類）|
